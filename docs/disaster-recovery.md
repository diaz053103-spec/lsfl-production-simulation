# LSFL Disaster Recovery

The LSFL environment includes disaster recovery exercises designed to demonstrate
how infrastructure teams recover from service or data failures.

## Recovery Objectives

### RTO

Recovery Time Objective defines the maximum acceptable time to restore a service.

### RPO

Recovery Point Objective defines the maximum acceptable amount of data loss.

## Recovery Process

1. Detect failure.
2. Assess impact.
3. Identify available recovery resources.
4. Restore service or data.
5. Validate application functionality.
6. Confirm system health.
7. Document recovery.
8. Identify improvements.

## Recovery Exercises

Planned simulations may include:

- Application service failure
- Database failure
- Corrupted configuration
- Lost application data
- Host failure
- Failed deployment
