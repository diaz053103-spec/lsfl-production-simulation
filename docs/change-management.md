# LSFL Change Management

Production changes follow a controlled process.

## Change Lifecycle

1. Change Request
2. Business/Technical Justification
3. Risk Assessment
4. Testing
5. Approval
6. Deployment
7. Validation
8. Rollback if required
9. Documentation

## Change Types

### Standard Change

Low-risk, repeatable change with an established procedure.

### Normal Change

Planned change requiring review and testing.

### Emergency Change

Urgent change required to restore service or address a critical security issue.

## Change Requirements

Every simulated production change should document:

- Change ID
- Description
- Reason
- Systems affected
- Risk
- Implementation plan
- Validation plan
- Rollback plan
- Result
