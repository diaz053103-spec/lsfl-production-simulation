# LSFL Operations Model

## Infrastructure Operations Responsibilities

The LSFL Infrastructure Operations team maintains the reliability of production
services.

Engineers are expected to:

1. Monitor system health.
2. Respond to alerts.
3. Investigate incidents.
4. Identify root causes.
5. Restore service.
6. Verify the recovery.
7. Document the incident.
8. Create preventive actions.

## Incident Lifecycle

Alert
→ Triage
→ Investigation
→ Mitigation
→ Recovery
→ Verification
→ Root Cause Analysis
→ Postmortem
→ Preventive Action

## Operational Priorities

1. Protect customer impact.
2. Restore service quickly.
3. Preserve evidence and logs.
4. Identify the root cause.
5. Prevent recurrence.

## Engineering Principle

Production changes should be repeatable, documented, tested, and reversible.
